# BlockLab — Block Cipher Modes of Operation

Interactive Assignment 4 website for **Om Pawar (Roll No. 24101A0057)**.

## Included
- ECB, CBC, CFB, OFB and CTR explanations
- Interactive toy model with plaintext/key/mode controls
- Comparison table
- Responsive dark UI suitable for Vercel

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
Push this folder to GitHub and import the repository into Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.

### Important
The interactive playground intentionally uses a simplified educational transformation. It is a visualization of mode mechanics, not production-grade cryptography. Do not use it to protect real data.
